### FR-005 场景宿主

- 优先级：P0
- 状态：已实现
- 目标：从一个容器创建独立 Three.js 实例。
- 说明：ThreeApp 同步创建自有 scene、PerspectiveCamera、WebGLRenderer、canvas；原生对象引用只读但对象可配置；默认不启动。
- 验收：初始 ready，无 RAF；无效相机/DPR 参数在分配 renderer 前失败；初始化后续失败回滚已建立资源；同页实例不共享状态。

### FR-006 统一帧循环

- 优先级：P0
- 状态：已实现
- 目标：可靠启动、停止与订阅每帧更新。
- 说明：start/stop 幂等；delta 以秒计，默认上限 0.1，恢复首帧为 0；订阅按顺序，返回取消函数，更新后宿主统一渲染。
- 验收：重复 start 只有一个 RAF；stop 后无帧；回调内 stop/start 不叠加循环，dispose 阻止本帧渲染；旧回调失效；更新异常停止并重新抛出。

### FR-007 尺寸与 DPR

- 优先级：P0
- 状态：已实现
- 目标：容器变化自动更新尺寸，稳定尺寸不重复配置。
- 说明：ResizeObserver、窗口 resize 与 DPR 媒体查询；DPR 默认上限 2；零尺寸和文档隐藏暂停调度，保留 running 状态。
- 验收：稳定尺寸不重复更新 drawing buffer；宽高比有限；零尺寸无 RAF，恢复 delta=0；DPR 变化刷新缓冲并受限；销毁解除监听。

### FR-008 资源所有权与释放

- 优先级：P0
- 状态：已实现
- 目标：幂等释放自有资源，保护借用资源。
- 说明：ResourceScope 显式 track/untrack，scope 内去重、逆序清理；不递归释放场景资源；dispose 时 abort signal 供业务判断异步结果。
- 验收：重复 dispose 无重复清理；清理异常仍执行剩余任务并聚合错误；借入共享 geometry/material 不被释放；销毁后 start/resize/订阅/track 抛错；通用 scope 不执行网络取消，模型加载另见 FR-011。

### FR-009 控制器与演示

- 优先级：P0
- 状态：已实现
- 目标：可选接入 OrbitControls，用真实场景验证公开 API。
- 说明：controls 独立子入口，共用主循环，手动或随 app 自动卸载；website 展示双实例生命周期操作。
- 验收：控制器无独立 RAF，卸载后不再 update；生产演示通过公开包名构建，双画布可渲染、独立暂停、resize、零尺寸恢复和反复销毁重建；无重复 canvas 和未处理页面错误。

### FR-010 GLTF / GLB 模型加载

- 优先级：P0
- 状态：已实现
- 目标：按需加载模型并保留 Three.js 原生数据。
- 说明：loaders 子入口的 loadGLTF 返回 GLTFModel；默认加入场景，可关闭自动挂载，不自动缩放、居中、改材质或播放动画。
- 验收：本地 GLTF 和 GLB 均由真实 GLTFLoader 解析和渲染，返回 scene/gltf/disposed/dispose；未知字节总量不假报百分比；失败拒绝原始错误，演示可恢复继续加载。

### FR-011 模型异步取消与资源归属

- 优先级：P0
- 状态：已实现
- 目标：避免宿主销毁后的迟到挂载，并正确释放模型自有资源。
- 说明：每任务独立逻辑取消，signal、宿主或 scope 结束立即拒绝 AbortError；迟到结果释放，不调用可能影响同 URL 请求的底层 abort。加载完成时拍摄资源快照，随句柄或宿主释放。
- 验收：取消不影响另一个同 URL 任务；取消/销毁后迟到成功被清理且不挂载，迟到失败无未处理拒绝；多 scenes 及共享 geometry/material/texture/skeleton 去重；之后新加入的借用资源不被接管；ImageBitmap 按缓存/所有权策略关闭或保留；同步挂载事件销毁宿主不会返回死模型。

### FR-012 模型演示与可重复 Fixtures

- 优先级：P0
- 状态：已实现

- 说明：项目自生成四面体 GLTF、GLB、内嵌 PNG 和故意不支持的 glTF 1.0；双实例页面提供加载、取消、移除与失败反馈。

## 非功能与安全边界

性能指标需先确定设备、模型规模、分辨率和基准场景，不编造 FPS、内存阈值。可靠性重点为生命周期、异常回滚、资源和事件清理。模型 URL、鉴权和 CORS 由应用及资产服务管理；客户端环境变量不作为保密机制。暂不需要数据库、后端认证、生产基础设施或遥测服务，未来按实际需求补充。

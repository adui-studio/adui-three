# ADR-0038 路径运行倍速

- 状态：Accepted
- 日期：2026-11-13
- 关联需求：FR-050、FR-036、FR-045、FR-046
- 替代关系：扩展 ADR-0024/0033/0034 的时间推进，不改变空间采样和有限程数

## 决策

PathMotionHandle 增加 readonly playbackRate:number 与 setPlaybackRate(rate:number):void，初始 1，允许非负有限数。只改变后续步长 (delta/duration)*playbackRate，保留当前曲线位置、朝向、有界 phase、剩余程数与 paused 状态；设置本身不采样、绘制或启动。seek 保留速度并继续沿用首程/预算重置规则，新句柄重新默认 1。

0 冻结时间和曲线采样，state 保持 running；宿主和其他运动可以继续。宿主更新仍执行所有者/目标保留检查，输入 signal、scope 或手动目标变化照常取消；pause/resume 不自动改变速度，0 倍速下 resume 仍冻结。结束/预取消句柄不能设置，新建运动才能重播。

## 数值与竞争

沿用分离整数程数/小数的有界推进算法，有限终点和返回方向不改变。有效参数不保证所有乘除组合均能在 Number 中表示；非有限缩放步长在新采样前 failed，不逐程循环。0 倍速不计算步长，不因大 delta 溢出，也不会在 seek(1) 预览后提前完成。

参数在变更前校验，所有者/目标失效沿用原取消策略。曲线采样和原生变换写入期间不能重入 setter，与 seek 使用同一写入保护；捕获重入错误可让当前采样继续，未捕获则当前运动 failed 并清理。没有新增队列、时钟、资源或 GPU 对象；模型动画的通知队列不套用到可借用的路径 Curve 回调。

## 验证

单测覆盖动态速度、无立即采样、零速度/另一目标、有限 repeat/往返历史、暂停/定位、非法输入、结束/预取消/替换、采样重入及缩放溢出。路径演示增加 A 倍速滑块并保留基准每程 2 秒；浏览器比较橙色箭头实际像素/拾取、另一目标继续、返回终点、外部修改取消及目标/宿主重建。包消费验证方法与 getter，实际结果见 Harness。

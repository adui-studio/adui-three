# ADR-0040 相机过渡运行倍速

- 状态：Accepted
- 日期：2026-11-13
- 关联需求：FR-052、FR-049、FR-047、FR-020
- 替代关系：扩展 ADR-0037 的共享暂停门控为运动时钟

## 决策

两种相机过渡句柄增加 readonly playbackRate:number 和 setPlaybackRate(rate:number):void，初始 1，非负有限数，仅缩放后续 delta。保留已用时间、姿态、镜头和原始进度；duration 是速度 1 时的基准宿主秒数。0 冻结运动但 state 仍为 running，pause/resume 不改变速度；宿主和其他对象继续更新绘制，无新循环或自动绘制。

沿用相机登记、输入/配置检查和资源租约。0 倍速或暂停期间，下一宿主更新仍可因外部修改取消；输入、signal、scope、替换仍结束运动。有限句柄结束后不能设置速度，getter 保留最后已应用值；预取消返回速度 1 的结束句柄。新过渡重新默认 1。

## 回调和终结

camera-runtime 共享内部时钟，初始化和原生姿态写入期间的速度/暂停请求延迟交接，当前帧按旧速度完整提交，后续帧使用新速度。各字段按调用顺序保留最后请求；getter 在提交前仍报告旧值。终点或异常先关闭时钟并丢弃尚未应用请求，不能在完成后再修改诊断速度。

非法速度在变更前 RangeError。非有限 delta*rate 在姿态写入前 failed，清理借用输入租约并传播异常；不承诺全部 Number 极值可表示。不支持负速度或倒播，保持原生控件、球面方向和节奏预设的现有语义。

## 验证

四种运动单测覆盖动态速度、无立即移动、零速度、暂停设置、初始化/原生回调延迟、终点请求丢弃及结束保护；非法输入和步长溢出另有回归。投影演示新增相机倍速滑块，只控制最新过渡，结束/重建禁用；浏览器同时读取原生 drawElements 计数与像素，核验 0 倍速时宿主仍绘制、进度/画面保持，2 倍速到达正确终点并保持输入取消。严格包消费验证句柄方法和 getter，结果见 Harness。
